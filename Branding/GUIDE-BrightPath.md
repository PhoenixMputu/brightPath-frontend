# BrightPath — Guide d'utilisation du logo

## L'idée
Le **b** de BrightPath est tracé comme un chemin qui s'enroule. Le **point jaune** est la lumière qui montre la direction : l'option qui convient à l'élève. On retrouve ce même point sur le **i** du nom.

## Versions
| Fichier | Usage |
|---|---|
| `lockup-horizontal.svg` | Version principale : site, en-tête des rapports, documents |
| `lockup-stacked.svg` | Formats carrés ou étroits : affiche, couverture, réseaux sociaux |
| `symbol.svg` | Symbole seul, à partir de 32 px |
| `symbol-small.svg` | Symbole renforcé pour les petites tailles (moins de 32 px) |
| `wordmark.svg` | Nom seul, quand le symbole est déjà présent ailleurs |
| `*-black.svg` | Impression noir et blanc (rapports photocopiés) |
| `*-white.svg` / `*-reversed.svg` | Sur fond bleu ou sur fond sombre |
| `export/` | Favicon, icônes d'app, icônes web, `head-snippet.html` |

## Couleurs
| Nom | HEX | RGB | CMJN (approx.) | Pantone (le plus proche, à vérifier sur nuancier) |
|---|---|---|---|---|
| Bleu RDC | `#0062C4` | 0 98 196 | 100 50 0 23 | 2935 C |
| Jaune Lumière | `#F7C400` | 247 196 0 | 0 21 100 3 | 7408 C |

Ces deux couleurs s'inspirent du bleu et du jaune du drapeau de la RDC. Le bleu est un peu plus foncé que celui du drapeau pour que le nom reste bien lisible sur fond blanc.

- Le bleu porte le logo et les textes. Son contraste sur blanc est suffisant pour le texte.
- Le jaune sert uniquement d'accent : le point, un bouton, un surlignage. **Jamais pour du texte sur fond blanc**, car il est trop clair pour être lu.
- Fonds autorisés : blanc, gris très clair, Bleu RDC (avec la version blanche). Sur photo ou fond sombre, utiliser la version blanche.

## Espace de protection
Autour du logo, laisser au minimum **la largeur du point jaune** sur chaque côté. Aucun texte ni image dans cette zone.

## Tailles minimales
- Logo horizontal : **120 px** de large à l'écran, **30 mm** à l'impression.
- Symbole : **32 px** avec `symbol.svg` ; en dessous (jusqu'à 16 px), utiliser `symbol-small.svg`.

## Typographie
- Nom dessiné à partir d'**Inter Display SemiBold** (licence SIL Open Font License, usage en logo autorisé), converti en tracés. Le point du i a été remplacé par le point jaune.
- Pour l'app et les rapports : **Inter** (Regular pour le texte, SemiBold pour les titres).

## À éviter
- Changer les couleurs, ou mettre le point dans une autre couleur que le jaune (sauf dans les versions une couleur).
- Déformer, étirer ou incliner le logo, ou ajouter une ombre ou un dégradé.
- Recomposer le nom avec une autre police, ou remettre un point normal sur le i.
- Placer le logo bleu sur un fond sombre ou chargé.
- Utiliser `symbol.svg` sous 32 px (prendre la version `symbol-small.svg`).

## À noter
- Avant de déposer la marque, faire vérifier le nom et le logo par un conseil en propriété intellectuelle, auprès de l'office de propriété industrielle de la RDC. Cette vérification n'a pas été faite ici.
- Alternative conservée : **Carrefour** (`alt-carrefour-*.svg`), dans la même palette.
- Version verte (Vert Avenir #0F5C4A + ambre #F5A400) conservée dans le kit précédent.
